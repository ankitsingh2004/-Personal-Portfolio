# Ankit Singh — Personal Portfolio Website

A clean, modern, and high-performance developer portfolio built with pure Vanilla HTML5, CSS3, and JavaScript. 
Designed with a code-editor aesthetic, clean glassmorphism accents, smooth responsiveness, and zero external build tools or framework dependencies.

---

## 🚀 Live Demo

- **Portfolio:** [Ankit Singh — Portfolio](https://github.com/ankitsingh2004)
- **Featured Live App:** [Personal Diet Planner](https://diet-planner-8hzzylecnqrwrsk3pdzvru.streamlit.app/)

---

## 📌 Features

- **Zero Build Step:** 100% Vanilla HTML5, CSS3, and modern ES6+ JS. No node modules, compilers, or heavy frameworks.
- **Editor-Inspired Theme:** Tabbed navigation matching IDE syntax, code-like structure, and interactive UI elements.
- **Dynamic Content Architecture:** All section data (projects, skills, experience, education, certificates) is cleanly separated in `script.js` for quick updates.
- **Project Showcase:** Filterable gallery highlighting MERN stack apps, Streamlit AI tools, and CS system utilities.
- **Certificate & Document Viewer:** Built-in modal lightbox to view image files and render inline PDFs natively.
- **Theme Control:** Supports Dark, Light, and System Theme preference persistence via `localStorage`.
- **Working Contact Form:** Direct asynchronous submission integration via Google Apps Script backend.
- **Fully Responsive & Accessible:** Optimized for screen readers, mobile devices, and reduced motion settings.

---

## 🛠️ Tech Stack & Dependencies

### Frontend & Core
- **HTML5 & CSS3:** Semantic markup, CSS Custom Properties (Variables), Flexbox, CSS Grid.
- **JavaScript (ES6+):** Dynamic DOM rendering, IntersectionObserver API, modular data structures.
- **Fonts:** Space Grotesk, Inter, JetBrains Mono (via Google Fonts).

### Backend & Integrations
- **Google Apps Script:** Asynchronous contact form processor writing entries to Google Sheets.
- **Deployment:** Vercel / Streamlit Cloud / GitHub Pages.
